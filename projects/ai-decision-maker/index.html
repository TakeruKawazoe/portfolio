RULE-BASED / LOW-CODE APPLICATION

AI Decision Maker

情報が多くて休日の行動を決めにくいとき、現在の所持金・体力・空腹度に合う候補をすぐに選べる意思決定支援アプリです。

01 / OVERVIEW

決断疲れを減らし、行動のきっかけを作る

解決したい課題

選択肢が多いと、休日に何をするか決めるだけでも迷いが生じます。情報を増やすのではなく、その時の状態に合う候補を絞る方法を考えました。

作った仕組み

所持金・体力・空腹度を入力すると条件に合う行動候補を抽出し、その中から一つを提案します。候補は利用者自身が追加・編集・削除できます。

入力
所持金・体力・空腹度
出力
条件に合う行動候補
管理
候補のCRUD
基盤
Microsoft Power Platform

名称について: 「AI Decision Maker」は制作物名です。生成AIや機械学習ではなく、Power Fxによるルールベースの条件抽出で動作します。

02 / LOGIC

入力から提案までを小さな処理へ分ける

01

条件入力

スライダーで所持金・体力・空腹度を入力し、その時の状態を短時間で指定できます。

02

候補の抽出

Filter関数で入力条件に合う行動候補だけを抽出します。

03

一つを提案

ShuffleとFirst関数を組み合わせ、抽出した候補から一つを表示します。

04

候補の追加

利用者が新しい行動パターンと条件を登録できます。

05

編集・削除

候補を使いながら内容や条件を見直し、不要な候補を削除できます。

06

データ連携

Excel Onlineをデータ保存先として接続し、候補を一覧で管理します。

03 / FLOW

意思決定の流れ

INPUT3つの状態所持金・体力・空腹度
→
FILTER条件抽出Power Fx
→
SELECTShuffle / First候補を一つ選ぶ
OUTPUT行動を提案すぐに確認

04 / UI & OPERATIONS

使う人が候補を育てられる設計

新規作成と編集を統合

varModeとPatch関数を使い、候補の新規作成と編集を同じ画面で扱えるようにしました。

処理状態を伝える

処理中の表示や保存完了の通知を用意し、操作を受け付けたか判断できるようにしました。

利用者が保守できる

提案ロジックを固定したままにせず、利用者が自分で候補と条件を更新できる管理画面を設けました。
